tetianavorobetski2022-art: Як ексортувати історію розмови з тобою у файл

GitHub Copilot: Ось кілька простих способів зберегти історію розмови у файл.

1) Через інтерфейс (web):
- Натисніть Ctrl+P → виберіть «Save as PDF» (Зберегти як PDF) → Зберегти.

2) Копіювання в текстовий файл:
- Виділіть текст розмови → Ctrl+C → Відкрийте Блокнот → Ctrl+V → Файл → Зберегти як → conversation.txt.

3) Через консоль браузера (швидко експортує видимий текст з основної області чату). Відкрийте DevTools (F12) → Console → вставте і виконайте цей код — буде завантажено файл .txt:

````javascript
// Вставити в консоль браузера на сторінці чату
(() => {
  const main = document.querySelector('main') || document.body;
  const text = (main && main.innerText) ? main.innerText.trim() : document.body.innerText.trim();
  const blob = new Blob([text], { type: 'text/plain;charset=utf-8' });
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  const dt = new Date().toISOString().replace(/[:.]/g,'-');
  a.download = `chat-history-${dt}.txt`;
  document.body.appendChild(a);
  a.click();
  a.remove();
  URL.revokeObjectURL(a.href);
})();
````

4) Через API: якщо користуєтесь API, зберігайте масив повідомлень (messages) у файл на боці сервера (JSON або текст).
